# Minecraft 原版素材源约定

## 权威素材源

仓库中的 `MC原版素材assets/` 是本项目 Minecraft Java 1.20.1 原版素材的唯一权威源。

新增或修复下列内容时，应优先直接从该目录按原版资源路径读取或复制：

- 方块纹理、方块状态与模型 JSON；
- 物品纹理与物品模型；
- 实体、玩家、盔甲等贴图；
- GUI、HUD、容器界面素材；
- 粒子、声音及其他 Minecraft 原版客户端资源。

## 禁止的默认回退

除非某项资源在 `MC原版素材assets/` 中确实不存在并且提交中明确说明原因，否则不得：

- 使用重新绘制的“仿 Minecraft”占位图代替已有原版素材；
- 从第三方网站下载同名素材作为默认来源；
- 把历史 `MC原版素材assets.zip` 当作构建或 CI 的真实素材源；
- 为了修复 UV/布局错误而直接修改原版 PNG 字节。几何、UV、颜色/tint、渲染层或布局错误应在运行时代码中修正。

## 构建产物

浏览器运行时可以继续使用 `assets/` 下的派生产物，例如纹理 atlas、裁切后的 GUI sprite 或选择性复制的实体贴图，但这些产物必须能够确定性地追溯到 `MC原版素材assets/`。

对于可以逐字节复制的资源，应保持与原版源文件一致；对于必须生成的 atlas/crop/tint，应由工具脚本确定性生成，并通过 CI 校验。

ZIP 读取能力只允许保留在合成测试或兼容旧工具的测试路径中，不得重新成为真实资源流水线的默认入口。
