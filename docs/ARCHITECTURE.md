# 架构记录

## 设计原则

1. **不复制 Java 版技术债。** 浏览器项目不会模拟单线程世界生成、每方块对象模型或无边界常驻内存。
2. **数据优先。** 区块以紧凑 TypedArray 保存，不为每个方块创建 JS 对象。
3. **并行优先。** v0.1 已把地形生成放入 Web Worker；后续把网格构建也迁入 Worker。
4. **渲染批处理。** 每个区块生成一个合并 `BufferGeometry`，只提交暴露面。
5. **资源生命周期显式管理。** 区块重建/卸载时释放旧 geometry，世界退出时释放 worker、纹理和材质。
6. **固定系统边界。** World / Player / UI 分层，避免把所有玩法塞进渲染循环。

## v0.1 模块

- `src/world-worker.js`：种子噪声、地形、海平面、基础树木生成。
- `src/world.js`：区块数据、方块读写、可见面网格、voxel raycast。
- `src/player.js`：输入、相机、AABB 碰撞、重力、跳跃、创造飞行。
- `src/ui.js`：HUD、快捷栏、物品栏展示、加载进度。
- `src/main.js`：状态机、场景、交互、主循环。

## 已知技术债

- 当前网格重建仍在主线程；频繁编辑大型区域会产生卡顿。
- 当前一次加载固定 5×5 chunks；还没有以玩家为中心的环形流式装卸。
- 水暂时作为非实体方块参与数据，但没有独立透明水材质和流体模拟。
- 存档尚未进入 IndexedDB。
- 生存值目前只是基础骨架，不是 Java 版精确公式。

这些项目会在后续 commit 中逐项拆除，而不是为了“看起来像原版”永久保留。
